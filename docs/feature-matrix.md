# DESRU feature matrix

DOOM Eternal Speedrun Utility (`DESpeedrunUtil`) is a WinForms app that attaches to `DOOMEternalx64vk.exe` with `WriteProcessMemory`. It does not inject a DLL. The in-game text in the top right is the game's performance-metrics strings; see `docs/osd-overlay.md`. The form speedometer is separate; see `docs/speedometer.md`.

| Feature                          | What it does                                                                                                             | Where                                                                      | Notes                                                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Process hook                     | Finds `DOOMEternalx64vk.exe`, reads `ModuleMemorySize`, picks a `GameVersion`, starts the 16 ms memory timer             | `MainWindow` hook path, `MemoryHandler` constructor, `GameVersion.cs`      | Unknown module sizes fall through to signature scans and `scannedOffsets.json`                                                                                                       |
| Offset tables                    | Per-build addresses for metrics rows, cheats, velocity, resolution scaling, cvars                                        | `Resources/offsets.json`, `MemoryHandler.Initialize`                       | `DeepPointer` turns an offset into `module base + offset`                                                                                                                            |
| On-screen display                | Rewrites the top-right metrics lines with version, flags, and cheat status; leaves `%i FPS` so the game still prints FPS | `MemoryHandler.MemoryTick`, `ModifyMetricRows`                             | Required visible for leaderboard runs. `*` means DESRU is out of date                                                                                                                |
| Minimal OSD                      | Packs version and flags into the first two metric lines and sets metrics mode `1`                                        | `minimal` flag, same tick                                                  | Forced on when `offsets.json` has `Metrics == 0`                                                                                                                                     |
| OSD font size                    | Writes `con_fontSize` (`5 + slider * 0.5`, or `10` to reset)                                                             | `SetOSDFontSize`, Settings page                                            | Also changes the dev console font                                                                                                                                                    |
| Flag letters                     | `M` macro, `F` firewall, `R` ReShade, `S` slopeboost off (1.0 only), `L` FPS cap not enforced                            | `SetFlag`, row 2 builder                                                   | Shown under the FPS counter                                                                                                                                                          |
| Cheat / Meathook line            | `CHEATS ENABLED`, `MEATH00K`, `MODDED CLIENT`, `RESTART GAME`, `RUN RESET`, `DESRU CLOSED`                               | Row 3 or the CPU string                                                    | `RESTART GAME` means the session is not valid until the game is relaunched                                                                                                           |
| External tools                   | `DoomEternalTrainer` stops OSD writes and raises `RESTART GAME` (unless Meathook). Cheat Engine raises `RESTART GAME`    | `RestartTick` (2.5 s)                                                      | Process-name scan, not a memory scan                                                                                                                                                 |
| Cheats toggle                    | Writes the console and binds bytes so cheats are on or off                                                               | `EnableCheats`, cheat offsets / `ScanForCheatsPointers`                    | Launch-parameter cheats are patched off at init (`LAUNCHPARAMS_GLOBAL_R`)                                                                                                            |
| Meathook                         | Detects `XINPUT1_3.dll` in the game directory; can install or remove it                                                  | `MainWindow.CheckForMeathook`, `InstallMeathook`                           | OSD shows `MEATH00K` instead of `CHEATS ENABLED`                                                                                                                                     |
| Firewall rule                    | Adds or removes a Windows Firewall rule for the game exe                                                                 | `Firewall/FirewallHandler.cs`, firewall button                             | `F` on the OSD while the rule exists. Info panel tells you to restart for valid runs after a change                                                                                  |
| Freescroll macro                 | Sends the bound up/down scroll keys on a timer while enabled                                                             | `Macro/FreescrollMacro.cs`                                                 | `M` on the OSD when enabled and a key is bound. Status label is Running / Stopped                                                                                                    |
| Scroll pattern                   | Counts wheel clicks and the average gap, shows it on the OSD for ~2 s                                                    | Form timer in `MainWindow.cs`, `SetScrollPatternString`                    | Replaces the cheat/status line while visible                                                                                                                                         |
| FPS cap                          | Writes `com_adaptiveTickMaxHz` (`MaxHz` offset)                                                                          | `SetMaxHz`, `CanCapFPS`                                                    | Default field is 250. Unsupported versions have a null pointer and skip the write                                                                                                    |
| Enforce 250 FPS                  | Keeps the cap applied while the checkbox is on                                                                           | `limiter` flag                                                             | `L` appears when this is off                                                                                                                                                         |
| FPS hotkeys                      | Up to 15 global keys, each stored with a target FPS in `fpskeys.json`                                                    | `Hotkeys/HotkeyHandler.cs`                                                 | Raw input on the main window, not `RegisterHotKey`                                                                                                                                   |
| Resolution unlock                | Rewrites the 32-float scale table so the minimum can go from 50% down to 1%                                              | `UnlockResScale`, `SetResScales`                                           | Waits until the game is focused and `rs_raiseMilliseconds` is in range, then alt-tabs to apply. 6.66 Rev 2 infers the minimum from the table (`rs_minimumResolutionScale` is absent) |
| Dynamic scaling                  | Sets `rs_enable` and raise/drop frametimes from a target FPS (up to 1000)                                                | `EnableDynamicScaling`                                                     | OSD scale line: `0.75x [250]` for 3 s after a change                                                                                                                                 |
| Static scaling                   | Sets `rs_forceResolution` and turns dynamic scaling off                                                                  | `EnableStaticScaling`                                                      | OSD bracket is `S`. The game's scaler still bottoms out near 10%                                                                                                                     |
| Auto scaling / unlock on startup | Schedules unlock, then enables dynamic or static scaling ~2.75 s after focus                                             | `ScheduleResUnlock`, `unlockOnStartupCheckbox`                             |                                                                                                                                                                                      |
| Res scale hotkeys                | One toggle, plus four keys that set a minimum percent                                                                    | `HotkeyHandler` res keys                                                   | Extra binds live behind "Show More Hotkeys"                                                                                                                                          |
| Version swap                     | Switches the installed game build from the version list                                                                  | `changeVersionButton`, `Resources/gameVersions.json`                       | "Download Downpatcher" opens the external downpatcher. `profile.bin` replace is limited to 3.1                                                                                       |
| Reset-run hotkey                 | Double-tap (500 ms) runs the keyboard script: pause if needed, enable cheats briefly, fire the script, restore cheats    | `HotkeyHandler`, `MemoryHandler` reset script, Settings "Enable Reset Run" | OSD shows `RUN RESET` until 5 s after cutscene id `1`. Optional "prevent automatic alt-tab"                                                                                          |
| Trainer readout                  | Reads velocity always; position, yaw, and pitch only with cheats or Meathook                                             | `ReadTrainerValues`, `GetPlayerVelocity`                                   | Horizontal m/s is `sqrt(vx² + vy²)`. Pointer chain is `VEL_OFFSETS_CURRENT` or `VEL_OFFSETS_OLD`                                                                                     |
| Form speedometer                 | Paints horizontal m/s, plus total or vertical, with a bar capped at 38.5                                                 | `MainWindow.Speedometer`                                                   | Allowed with cheats off. Can hide during loads and right-align                                                                                                                       |
| In-game trainer text             | Replaces OSD rows with `vel:`, position, `h:` / `v:`, yaw, pitch                                                         | `trainer` flag inside `MemoryTick`                                         | `vel:` is total speed, not the speedometer's horizontal value. Needs cheats or Meathook                                                                                              |
| Anti-aliasing cvar               | Writes the AA byte off                                                                                                   | Settings, `SetCVAR("antialiasing")`                                        | No effect while DLSS is on                                                                                                                                                           |
| UN quitout delay                 | Clears `pauseMenu_delayUNPrompt` so Ultra-Nightmare can be left without the delay                                        | `undelay` cvar                                                             | Version-dependent; the pointer may be zero                                                                                                                                           |
| Auto-continue                    | Sets `com_skipKeyPressOnLoadScreens` so loads advance without input                                                      | `autocontinue` cvar                                                        |                                                                                                                                                                                      |
| Console hotkey                   | `con_advancedKeypress` plus the chosen dev-console key; optional Ctrl+Shift+`                                            | Settings, `AdvancedConsoleKeypress`                                        | Reduces accidental console opens                                                                                                                                                     |
| RTSS                             | Option to start RTSS with DESRU; info panel shows whether `rtss` is running                                              | `launchRTSSCheckbox`, `StatusTick`                                         | Not required for the OSD                                                                                                                                                             |
| Info panel                       | Game, FPS cap, cheats, macro, slopeboost, balance updates, ReShade, res scaling, hotkeys, RTSS                           | `StatusTick`                                                               | Longer interval than the 16 ms memory tick; firewall checks live here because they cost ~8 ms                                                                                        |
| Update check                     | Compares the running build to the remote version and can hand off to `Updater`                                           | `UpdateDialog`, `Updater/Program.cs`                                       | Out of date sets the OSD `*`                                                                                                                                                         |
| Run-validity OSD                 | The metrics patch is the moderation signal: version, flags, cheats, restart                                              | Help text in `Properties/Resources.resx` (`HelpPage_OSD`)                  | DESRU must be running before the game is launched                                                                                                                                    |

## Timer split

| Timer                         | Interval                        | Work                                                                                             |
| ----------------------------- | ------------------------------- | ------------------------------------------------------------------------------------------------ |
| `MemoryHandler.MemoryTimer`   | 16 ms (`Program.TimerInterval`) | Deref pointers, read trainer values, rewrite OSD strings, apply FPS cap and scheduled res unlock |
| `MemoryHandler` restart timer | 2500 ms                         | Look for DoomEternalTrainer and Cheat Engine                                                     |
| Main form timer               | 16 ms                           | Speedometer paint, scroll-pattern tracking, push macro / limiter / trainer flags into `Memory`   |
| `StatusTick`                  | Longer than the form timer      | RTSS, firewall rule, info-panel labels                                                           |
